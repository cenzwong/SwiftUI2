# SwiftUI2 Architecture Overview

SwiftUI2 is a native Swift SDK for on-device intent detection, instant previews, and safe action execution powered by Apple Intelligence and Foundation Models.

## Architectural Principles

1. **Fundamental Pipeline**: Intent Input → Structured Proposal → Live Temporary Preview → User Commit → Action Execution.
2. **Preview/Commit Separation**: Model inference and preview generation never mutate persistent application state. Mutations occur strictly inside user-authorized commit handlers.
3. **Latest Revision Wins**: Input and context carry monotonically increasing revision numbers. Stale proposals generated by older inputs are automatically discarded.
4. **Platform Independence**: `SwiftUI2Core` and `SwiftUI2Testing` have zero dependencies on `SwiftUI` or `FoundationModels`, allowing complete unit testing without hardware or UI dependencies.

## Module Structure

```
SwiftUI2/
├── Sources/
│   ├── SwiftUI2Core/          # Domain models, state engine, scheduler, commit executor
│   ├── SwiftUI2AppleModels/   # Apple Foundation Models adapter & dynamic schema generation
│   ├── SwiftUI2SwiftUI/       # SwiftUI controller, text fields, and view modifiers
│   └── SwiftUI2Testing/       # Mock intent models & scripted test datasets
├── Tests/
│   ├── CoreTests/
│   ├── AppleModelTests/
│   ├── SwiftUITests/
│   └── IntegrationTests/
└── Examples/
    └── ReminderDemo/          # Complete standalone reference application
```
